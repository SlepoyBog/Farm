# Демонстрационные данные

Файлы аналитики в этом каталоге обезличены и содержат синтетические значения. Они нужны только для демонстрации формата состояния и работы аналитических модулей.

Рабочие идентификаторы публикаций, аккаунтов, каналов и исторические метрики в текущей версии репозитория не публикуются.
